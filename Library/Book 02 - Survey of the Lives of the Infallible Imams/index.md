# Book 02 — A Survey into the Lives of the Infallible Imams

This folder applies the **Deep-Reading Framework v1.1** to Ayatullah Murtadha Mutahhari's *A Survey into the Lives of the Infallible Imams*.

## Source → study → exam pipeline

```
Al-Islam source
   ↓
data/chunks.json              160 verified source-understanding chunks
   ↓
data/study_book02.json        structured concepts / terms / key phrases /
                              claim → reasoning → evidence → lesson /
                              20 cross-unit connections / master questions
   ↓
study_guide/study.html        interactive study + score + spaced review
   ↓
exam_bank/
   ├── questions.json         master question universe
   ├── unit_tests.html        every reading unit
   ├── full_book_exam_generator.html
   └── MASTER_20_SIMULATED_YEARS.html
   ↓
mind_maps/book02_interactive.html
```

## Reading units

13 reading units are covered: Foreword; Introduction; Chapter 1; Chapter 2 Sessions 1–2; Chapters 3–7; and Chapter 8 Parts 1–2.

## Exam philosophy

The actual exam may be short; this library deliberately is not. The master bank over-prepares through:

**source fact → precise recall → distinction → explanation → claim/example → cross-unit synthesis → interleaved full papers → hard/worst-case paper**

All generated exams draw from the same question IDs rather than creating a separate question universe for each paper.
