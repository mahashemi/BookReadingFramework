# Exam Bank

The Book 02 master question universe contains **872 questions** spanning all 13 reading units.

`questions.json` is the source of truth.

The exam layer contains unit tests, 3-unit tests, half-book tests, full-book tests, simulated Years 1–20, and a Hard/Worst-case paper. Default simulated paper format is 4 objective questions + 7 written questions, interleaved across units.

The 20 simulated years deliberately reuse the same master universe. They are practice papers, not predictions of an actual exam.
