About the project

BookReadingFramework

A scholarly digital learning library for turning serious books into structured, source-traceable learning environments.

What we are building

BookReadingFramework connects original source texts to learning units, concepts, evidence, glossaries, practice, assessment, review, and teaching materials. The aim is not to replace a book with a summary, but to make deep reading easier while preserving provenance.

Each learning concept is linked back to the source passage from which it was developed. The framework is designed to be reusable across books and transparent enough to inspect, correct, and extend.

Method

Read → Understand → Practice → Teach. Source material remains the canonical layer; the learning layer is maintained around it.
