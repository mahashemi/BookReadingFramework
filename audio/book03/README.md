# Book 03 narration scripts

These scripts are the editorial layer for the future professional audiobook of **Jihad bil-Nafs**.

## Two layers

1. **Source-grounded narration** — a faithful spoken paraphrase of what the source chapter develops, anchored to the learning chunks already mapped to the canonical Ahlulbayt Library transcription.
2. **Deep Reading insight** — an explicit framework interpretation: why the idea matters, how it connects to another unit, and how a listener might turn it into a repeatable practice.

The second layer is not presented as a quotation or as the author's own wording. The narrator should use phrases such as "The text is emphasizing..." and "For our deep-reading purposes..." so the boundary remains audible.

## Intended audio modes

- **Listen to the Book:** source-oriented narration with minimal interpretation.
- **Listen & Learn:** source narration plus the Deep Reading insights, connections, practical reflection, and pauses in these scripts.

No audio binaries belong in Git. These Markdown scripts are the editorial source for future professional recordings.

## Narrator direction

Persian should sound natural and contemplative rather than like a classroom lecture. Arabic quotations should be pronounced carefully and briefly, with a small pause before and after them. Do not rush transitions: the purpose is to let a listener follow the argument without looking at a screen.

Each unit should feel like one coherent journey:

**question → source idea → consequence → connection → practice → reflection → transition.**

## Provenance

The Source map at the end of each script names the exact learning chunk IDs used to construct the narration. Those chunks point to the canonical source transcription and its page anchors.

The scripts intentionally paraphrase rather than reproducing long passages from the source.
