# BookReadingFramework

A reusable, data-driven framework for deep reading, active recall, exam preparation, and teaching materials.

## Books

### Book 02 — A Survey into the Lives of the Infallible Imams

The Book 02 workspace contains the source extraction layer, structured study model, master question universe, interactive study guide, unit/full-book/interleaved exam tools, 20 simulated exam years, mind maps, and modular teaching materials.

Start with the [Book 02 study guide](Library/Book%2002%20-%20Survey%20of%20the%20Lives%20of%20the%20Infallible%20Imams/study_guide/study.html).

The study model lives in `data/study_book02.json`; all testable questions live in the single-source-of-truth `exam_bank/questions.json`.
