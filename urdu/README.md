# اردو مطالعہ — تراجم اور مطالعہ جاتی رہنما

یہ حصہ اصل کتابوں کے اردو تراجم کو باب بہ باب محفوظ کرتا ہے۔ ہر صفحہ اصل ماخذ سے منسلک ہے اور دائیں سے بائیں (RTL) ترتیب میں ہے تاکہ اسے Safari میں پڑھا اور Safari کی دستیاب اردو آواز سے سنا جا سکے۔

## اداریاتی اصول

- ہر صفحے پر واضح کیا جاتا ہے کہ وہ اردو ترجمہ ہے یا مطالعہ جاتی خلاصہ؛ خلاصے کو لفظ بہ لفظ ترجمہ نہیں سمجھنا چاہیے۔
- نام، قرآنی آیات، روایات، تاریخی دعووں اور حوالہ جاتی حواشی کی جانچ اصل باب کے ساتھ کی جائے گی۔
- ہر صفحے پر اصل ماخذ کا ربط دیا گیا ہے؛ مسودوں کو حتمی تنقیدی ایڈیشن نہ سمجھا جائے۔
- اس کام میں آف لائن ماڈل یا آڈیو فائل بنانے کا مرحلہ شامل نہیں؛ آڈیو کے لیے مقامی Safari استعمال کیا جا سکتا ہے۔
