# اردو مطالعہ — Deep Reading

یہ فولڈر کتابوں کے لیے اردو مطالعہ جاتی مواد فراہم کرتا ہے۔ مواد کو مرحلہ وار، ایک باب یا تعلیمی یونٹ کے حساب سے شامل کیا جائے گا۔

## ادارتی اصول

- موجودہ مرحلے میں صرف **متن کا اردو ایڈیشن** بنایا جا رہا ہے؛ آف لائن ماڈل، آڈیو جنریشن یا خودکار اشاعت اس کام کا حصہ نہیں۔
- مواد کو واضح RTL (دائیں سے بائیں) ترتیب اور براؤزر میں پڑھنے کے قابل HTML میں رکھا جائے گا، تاکہ Safari کی دستیاب اردو آواز سے بھی اسے سنا جا سکے۔
- یہاں موجود صفحات Deep Reading Framework کے اپنے خلاصوں، تصورات اور مطالعہ جاتی نوٹس کے اردو روپ ہیں؛ یہ ناشر کی اصل کتاب کا مکمل متبادل یا لفظ بہ لفظ ترجمہ نہیں ہیں۔
- اصل ماخذ، مصنف کے استدلال، تاریخی دعووں اور ہماری وضاحتی تشریح کے درمیان فرق برقرار رکھا جائے گا۔
- ناموں، دینی اصطلاحات، قرآنی حوالوں اور معاہدوں کی شرائط میں احتیاط برتی جائے گی؛ جہاں ضروری ہو اصل ماخذ سے ربط دیا جائے گا۔
